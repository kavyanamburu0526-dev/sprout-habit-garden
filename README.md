# Sprout - Your Little Habit Garden
Sprout is a gamified habit-tracking web application that transforms daily routines into an interactive virtual garden.
# Features
- Create, edit and delete daily habits.
- Track daily habit completion.
- Earn seeds for completing habits.
- Grow a virtual garden.
- Purchase plants using collected seeds.
- Track daily consistency streaks.
- Unlock achievements.
- Visualize weekly progress.
- Persistent SQLite database storage.
# Technology Stack
Frontend: HTML, CSS, JavaScript
Backend: Python, Flask
Database: SQLite
# Installation
1. Clone the repository.
2. Create a virtual environment.
3. Install dependencies:
pip install -r requirements.txt
4. Run the application:
python app.py
5. Open your browser:
http://127.0.0.1:5000
